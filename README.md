# Movie Search App 🎬

تطبيق بحث عن الأفلام يعرض الأفلام الشائعة والأكثر بحثاً باستخدام React و TMDB API و Appwrite.

## 🚀 التقنيات المستخدمة (Tech Stack)
* **React 18** + **Vite**
* **Appwrite Database** (لحفظ عداد البحث والأفلام الشائعة)
* **TMDB API** (لمعطيات البيانات والأفلام)
* **Tailwind CSS**
